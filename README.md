
# 💰 Billing Management System

## 📋 Description
A complete web-based billing management application
built with PHP and MySQL. The application allows
administrators to manage clients, create and track
invoices, and monitor payment status through a
secure and intuitive interface.

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML / CSS
- JavaScript
- XAMPP / WAMP

## ⚙️ Installation Instructions

1. Install a local server such as XAMPP that 
   supports PHP and MySQL.

2. Copy the project folder into the XAMPP 
   "htdocs" directory:
   Example: C:\xampp\htdocs\gestionDesFacturations

3. Open phpMyAdmin at:
   http://localhost/phpmyadmin

4. Create a database named "facturation"

5. Import the provided database file 
   (facturation.sql) into phpMyAdmin.

6. Open VS Code, open the "gestionDesFacturations" 
   folder and configure the MySQL credentials 
   in the configuration file:
   - Host: localhost
   - Username: "your_mysql_username"
   - Password: "your_mysql_password"

7. Launch the application in your browser at:
   http://localhost/gestionDesFacturations/login.php

## ✨ Features
- 🔐 User authentication (login)
- 📊 Dashboard with a summary of clients 
  and invoices
- 👥 Client management:
  - Add, edit, delete and list clients
- 📄 Invoice management linked to clients:
  - Create an invoice
  - View a client's invoices
  - Edit an invoice
  - Delete an invoice
  - Change invoice status
- ➕ Add multiple products or services 
  to an invoice
- 💾 Save changes
- 🧮 Automatic calculation of invoice total
- 👁️ Invoice display with payment status 
  (paid / unpaid)
- 🖨️ Printable preview of each invoice

## 🗄️ Database
- Database name: facturation
- File: facturation.sql
